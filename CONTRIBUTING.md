# Contributing to OpenCourt LA

OpenCourt is currently in personal-MVP territory but welcomes lightweight contributions, especially:

## Court additions or corrections

If you spot a missing court or incorrect info, open a GitHub Issue with:

- **Name** of the facility
- **Address** or coordinates
- **Sport(s)** — tennis, pickleball, or both
- **Access tier** — free / low-cost (< $20/hr) / private-members
- **Court count** (best estimate)
- **Notes** — anything useful: lighting, surface condition, reservation system, weekday vs weekend patterns

Include "[Court submission]" in the title to help triage.

## Bug reports

Open an Issue with:

- Browser + OS
- Steps to reproduce
- What you expected vs what happened
- A screenshot if visual

## Code contributions

OpenCourt v1 is intentionally simple — plain HTML/CSS/JS, no build step, no dependencies beyond Google Maps and Google Fonts. Please keep PRs aligned with that aesthetic.

For bigger changes (new features, refactors, framework introductions), open an Issue first to discuss before coding.

## Code of conduct

Be kind. Be specific. Be useful.
